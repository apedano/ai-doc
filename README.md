# Stanford Video Lessons on Agentic AI

Stanford University has significantly expanded its public video lectures and seminar series dedicated to **Agentic AI**. Key courses, lecture series, and resources cover AI agents, tool integration, test-time compute scaling, and multi-agent coordination.

---

## Key Stanford Courses & Video Playlists

### 1. CS329A: Self-Improving AI Agents
This specialized, advanced course covers state-of-the-art research on building AI agents that learn and adapt through interaction.
* **Core Topics Covered:**
  * Test-time compute scaling & inference-time search
  * Robust verification (verifiers for mathematics and code generation)
  * Tool augmentation (API integration, code execution, persistent long-term memory)
  * Multi-step reasoning & planning algorithms
  * Multi-agent orchestration and coordination
* **Guest Speakers:** Industry leaders and researchers from AI labs (e.g., Reflection AI, Google DeepMind) presenting on real-world agent deployments.
* **Access:** Lecture recordings and syllabus schedules are hosted on the [Stanford CS329A Course Site](https://cs329a.stanford.edu/) and syndicated on the **Stanford Online** YouTube channel.

---

### 2. CME295: Transformers and Large Language Models
While covering general LLM architectures, this graduate-level course features complete modules dedicated to **Agentic Systems**.
* **Core Topics Covered:**
  * Transitioning from passive next-token prediction to active task execution
  * Function calling and dynamic tool usage
  * ReAct (Reasoning + Acting) execution loops
  * Benchmark evaluation methodologies for autonomous agents
* **Access:** Available via the dedicated CME295 playlist on the [Stanford Online YouTube Channel](https://www.youtube.com/@stanfordonline/playlists).

---

### 3. CS25: Transformers United (Seminar Series)
CS25 regularly invites leading researchers to present cutting-edge agentic workflows and specialized domain applications.
* **Notable Agentic Topics:**
  * Autonomous multi-agent hypothesis generation (e.g., AI Co-Scientist systems)
  * Diagnostic and conversational medical AI agents (e.g., AMIE framework)
* **Access:** Video recordings are updated regularly on the official **CS25: Transformers United** playlist via Stanford Online.

---

### 4. CS224R: Deep Reinforcement Learning
Modern agentic architectures depend heavily on Reinforcement Learning (RL) techniques for post-training, alignment, and environment interaction.
* **Core Topics Covered:**
  * Markov Decision Processes (MDPs) and policy optimization
  * Reward modeling and feedback-driven adaptation
  * Environment interaction dynamics for sequential decision-making
* **Access:** Search for the **CS224R** course playlist on the Stanford Online YouTube channel.

---

## Recommended Learning Path & Materials

| Course / Resource | Primary Focus | Best For |
| :--- | :--- | :--- |
| **CS329A** | Self-Improving Agents, Planning, Verifiers | Advanced Builders & AI Engineers |
| **CME295** | ReAct Loops, Function Calling, LLM Tools | Applied Developers & Practitioners |
| **CS25** | Frontier Research Seminars, Multi-Agent Systems | Researchers & System Architects |
| **CS224R** | Deep RL Foundations & Sequential Control | Core ML / RL Engineers |

2. **Course Portals & Reading Lists:**
